AWS Architecture

Core AWS services used for the Soulinspire infrastructure build.

This front-end application is suitable for deployment on Amazon S3 with CloudFront, while the full platform can extend into EC2, VPC, CloudWatch, SNS, backups, and budget monitoring.

01

Amazon S3

Stores and hosts static website files including HTML, CSS, JavaScript, and assets.

02

Amazon CloudFront

Delivers the website globally through a CDN with HTTPS and faster user access.

03

Amazon VPC

Provides secure network isolation for application servers and backend services.

04

Amazon EC2

Can run backend application services if Soulinspire requires dynamic processing.

05

Amazon CloudWatch

Monitors performance, logs, metrics, alarms, and operational health.

06

Amazon SNS

Sends alerts to administrators when alarms, downtime, or usage limits are triggered.

Amazon S3
Static website hosting

Amazon S3 stores the static application files and can serve the website when configured for static hosting. For production, S3 should be paired with CloudFront for HTTPS, caching, and secure delivery.
